1. Zoom Clone

A real-time video calling application enabling peer-to-peer video/audio communication, built with WebRTC for media streaming and Socket.io for signaling. Deployed on Render.

Features:
  • Real-time peer-to-peer video and audio calls
  • Room-based joining with unique meeting links
  • Socket.io signaling for connection negotiation
    •
Tech Stack: React.js, Node.js, Express.js, WebRTC, Socket.io
Challenges: Handling NAT traversal and connection drops across different networks.
